# {{NAME}}

本文描述仓库内 Agnes 图像适配器的当前实现，不代表渠道账号一定拥有所有模型权限。图像请求通过后端渠道提交；网页只选择模型、输入提示词与引用素材，不应在提示词、画布节点或错误报告中写入真实密钥。

## 接口与鉴权

{{OPERATIONS}}

该协议使用 JSON 同步生成请求，不建立单独的轮询任务。渠道根地址与相对路径由宿主拼接，鉴权由后端渠道层提供。部署时先用无敏感内容的小请求确认地址与账号授权，避免直接用整批生产素材试错。

## 模型与支持边界

模型 ID 来自渠道配置，适配器不会自动更换模型。元数据列出的 Agnes 图像系列仅用于选择协议；不同账号实际支持的模型、质量与参考图片数量需在渠道侧确认。当前实现支持提示词、宽高比、尺寸档位、参考图片和请求数量，不把未适配的蒙版或视频输入宣传为已支持。

## 参数与字段映射

{{PARAMETERS}}

请求始终包含 `model`、`prompt` 和 `size`；`quality` 为空时尺寸档位默认 `1K`。非空 `aspectRatio` 写入 `ratio`，正数 `imageCount` 写入 `n`。参考图优先取 URL，其次取 data URL，组成 `extra_body.image` 数组；响应格式固定在 `extra_body.response_format` 中要求 `url`。

扩展参数不能覆盖上述关键字段。质量档位是否可用仍由实际模型决定，不能把默认值当作供应商承诺。引用图片应保持任务期间可访问；不提交需要浏览器 Cookie 的地址。

## 响应与排错

创建响应经过共享图片结果解析器提取图片地址或 Base64 图片。HTTP 成功但没有可识别图片不等于业务完成。排查失败时核对渠道地址、模型名、响应结构和非敏感错误信息；不要复制请求鉴权头。该适配器没有轮询路径，不应将异步任务 ID 误当图片链接展示。

## 官方资料与验证边界

模型授权、价格和服务限额以所用 Agnes 渠道的官方文档与控制台为准。本页的可执行合同来自 `builtin.go` 中的 `agnesImagesAdapter`，并未对供应商在线能力作额外保证。升级供应商接口后须补请求与响应测试，不能只修改界面文字。
