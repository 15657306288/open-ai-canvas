# {{NAME}}

该适配器把宿主的视频请求转换为 JSON 创建任务，再以任务 ID 查询结果。它与红鸟图像协议的路径、媒体输出类型不同，不能仅更换模型名就混用。部署时先核对所装插件和渠道配置，避免把协议未安装当成供应商生成失败。

## 接口与鉴权

{{OPERATIONS}}

鉴权由后端渠道层提供，创建和轮询复用同一渠道身份。请求不采用 multipart 文件上传；参考媒体通过 URL 或适配器支持的媒体值传递。用户电脑上的本地路径、受浏览器 Cookie 保护的链接不应作为供应商输入。

## 模型与支持边界

模型名称由请求提供并原样发送。适配器不内置价格表或账号额度，也不保证所有模型都接受音频、视频或多图参考。是否支持这些输入需由实际模型与已安装插件的配置共同决定。未经验证的参数不会因为出现在通用表单中就自动获得上游支持。

## 参数与字段映射

{{PARAMETERS}}

请求始终写入 `model`、`prompt` 和整数秒数 `seconds`；时长使用当前实现的缺省值 5 秒。非空 `aspectRatio` 写入下划线字段 `aspect_ratio`。参考图片、音频和视频分别通过 `images`、`audios`、`videos` 数组提交，仅非空数组进入请求。

`generateAudio` 为真时才写入 `generate_audio: true`；为假时省略该字段。当前创建逻辑不发送通用质量、分辨率或种子字段，因此不能把这些通用元数据字段当成此适配器已完成的映射。需要新参数时须同时修改请求构造和测试。

## 响应与排错

创建返回任务标识后，宿主通过视频异步解析路径持续查询。任务未完成时不伪造资源地址；供应商返回失败或取消时保留失败语义。已成功但没有可识别视频链接属于协议错误，应检查响应字段，不能仅把重试间隔调大掩盖问题。

排障可记录模型、路径、状态和脱敏错误。不要把整段带凭据的上游请求贴到反馈里。视频输出进入宿主资源保存流程后才可作为持久素材使用，供应商临时 URL 不等于已备份。

## 官方资料与验证边界

渠道官方文档负责说明账号权限、最新模型与输入限制；本文只描述 `builtin.go` 中 `hongniaoVideosAdapter` 的请求合同。声明式插件包可采用不同实现，应查看实际部署包的接口文档，而不是依赖历史界面提示。
