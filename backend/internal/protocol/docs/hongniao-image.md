本文记录仓库内红鸟图像适配器，而非所有红鸟插件包的通用合同。生产渠道使用已安装插件时，应同时检查插件版本及其接口文档；内置适配器的存在不代表该插件已安装或对当前用户开放。

## 接口与鉴权

{{OPERATIONS}}

创建请求使用 JSON，后续按返回的任务 ID 查询图片结果。渠道凭据通过后端注入；不要在 Base URL 查询参数、参考图片地址、节点内容或日志里放入密钥。创建与查询需指向同一渠道，不能跨渠道复用任务 ID。

## 模型与支持边界

模型名由渠道配置传入。当前实现按模型名是否以 `banana2` 开头区分质量字段，其余名称进入另一种质量映射。这是明确的代码分支，不是按名称推测可用额度、价格或内容限制。模型不接受对应请求结构时应修改适配器并补测试，而不是反复重试同一个无效请求。

## 参数与字段映射

{{PARAMETERS}}

所有请求包含 `model` 和 `prompt`。非空 `aspectRatio` 写入 `aspect_ratio`，参考图片集合写入 `images`。`banana2` 前缀模型把 `quality` 转为小写，只有 `2k` 保留为 `2k`，其他值按当前实现使用 `1k`，字段名是顶层 `resolution`。

其余模型使用 `parameters.quality`：`medium`、`1k`、`standard` 映射为 `medium`；`low`、`fast`、`draft` 映射为 `low`；其他值映射为 `high`。此分支不写顶层 `resolution`。未在这些逻辑中发送的通用元数据字段不能视为已经实现。

## 响应与排错

该协议复用异步媒体解析路径，创建后保存任务身份，查询时区分等待、执行、成功和失败。成功任务必须返回可识别的图片，不能凭 HTTP 200 或非空任务 ID 宣称图片已生成。下载链接有访问要求时由资源流程处理，不能将后端鉴权信息暴露给浏览器。

## 官方资料与验证边界

在线可用模型和限制应以所选渠道维护者的官方说明为准。本页依据 `builtin.go` 的 `hongniaoImagesAdapter` 编写；声明式插件包有独立版本和运行边界，不能照搬另一插件的参数。排障记录仅包含脱敏字段与实际响应状态，不记录密钥。
