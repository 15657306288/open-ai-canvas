# 电商平台图片规范

用户给出平台（淘宝/京东/拼多多/抖音/小红书/Amazon）时优先应用本技能，不要再往下猜。平台规则会变，无法核验时明确写「尚未核验平台最新规则」。

## 国内平台

### 淘宝 / 天猫

- 主图 1:1（800x800，最低 700px），纯白底 RGB(255,255,255)，商品占比 >= 80%
- 附图最多 20 张，JPG/PNG，单张 <= 3MB
- 套图顺序：白底主图 -> 卖点图 x2 -> 材质图 -> 场景图 -> 模特图 -> 多场景图
- 禁止：牛皮癣广告、过度文字水印、伪造品牌标识

### 京东

- 主图 1:1（800x800，最低 400px），白底、无水印、商品居中
- 附图最多 10 张，JPG，单张 <= 2MB
- 文案风格：专业理性，强调参数与服务保障

### 拼多多

- 主图 1:1（750x750，最低 480px），白底转化率更高
- 附图最多 10 张，单张 <= 3MB
- 文案风格：简洁直白，强调价格优势与实用价值

### 抖音电商（抖店）

- 主图 1:1（800x800）或 3:4（600x800）；短视频封面 9:16（1080x1920）
- 文案风格：年轻化、场景感强，生活化场景优先

### 小红书

- 图片 3:4（1080x1440）或 1:1（1080x1080），美感优先、生活化场景

## 跨境平台

### Amazon

- 主图最小 1000x1000，推荐 2000x2000；纯白背景，商品占面积 >= 85%
- 禁止文字、水印、边框、装饰；附图最多 9 张
- A+ 内容图宽度 970px 或 1464px
- 英文文案：专业简洁，强调功能与规格

## 文案语言规范

- 中文主标题 <= 12 字；副标题 <= 15 字
- 英文主标题 <= 5 词；副标题 <= 8 词

## 套图优先级

| 平台 | 必做图 | 推荐图 | 可选图 |
| --- | --- | --- | --- |
| 淘宝/天猫 | 白底主图、卖点图 | 材质图、模特图 | 多场景图 |
| 京东 | 白底主图、核心卖点图 | 材质图、场景图 | 模特图 |
| 拼多多 | 白底主图 | 卖点图、场景图 | 模特图 |
| 抖音 | 场景图、模特图 | 卖点图 | 多场景图 |
| Amazon | 白底主图 | 核心卖点图、场景图 | 模特图、材质图 |
| 独立站 | 模特图、场景图 | 白底主图、材质图 | 多场景图 |
