# 女装皮草与食品生鲜品类打法

先判断品类再执行。两类的视觉重点、卖点结构与合规红线完全不同，混用会直接产出错误素材。

## 女装皮草

### 材质表现是核心

皮草的成交取决于买家能不能从图上看懂「这是什么皮、什么工艺、值不值这个价」。

- 皮种必须写实：貂皮、狐狸、貉子、兔皮、绵羊皮的毛感与光泽完全不同，不得互相替代或美化。
- 工艺要点可视化：双层拼穿、镶嵌、割毛、拼接、手工缝制等要在细节图里看得见针脚与走线。
- 毛向与绒密度是卖点：冬季保暖靠的是绒厚与毛密，逆光或侧光更能表现毛流感，正面平光会让皮草显得廉价。
- 颜色要准：染色皮草容易偏色，同一批次要保持一致，详情页多角度不得出现明显色差。

### 版型与场景

- 版型图要能看出肩线、领型、袖型、衣长，这是退货率的主要来源。
- 上身图必须符合身高与尺码标注，不要生成与尺码表矛盾的体型。
- 场景优先：城市街拍、办公场合、宴会、雪景，体现身份与质感而非堆砌。

### 卖点结构

从 Feature -> Advantage -> Benefit -> Evidence 取 Top 3：

- 材质：真皮种 + 克重 + 产地
- 工艺：镶嵌 / 双层 / 手缝等具体做法
- 版型：肩线、收腰、显瘦比例
- 保暖：适合温度区间（客观描述，不夸大）
- 搭配：可配什么内搭与下装

### 红线

- 不得把化纤仿皮草描述为真皮草，不得模糊「皮草」与「仿皮草」。
- 不得使用「治疗」「助孕」「改善循环」等功效表述。
- 涉及「进口」「濒危物种原料」需真实凭证，否则不得主张。

## 食品三农生鲜

### 视觉重点是新鲜度与真实感

生鲜类最怕「拍得像塑料」或「与实物不符」，收货落差直接毁掉复购。

- 呈现真实状态：蔬菜带叶带根、水果带纹理与自然瑕疵、肉禽类体现新鲜色泽与湿润质感。
- 产地环境可选但不得虚构：写明「产地实拍」需要真实素材，否则只用通用田园场景。
- 避免过度修饰：过饱和、强反光、塑料感包装会降低信任。
- 规格要给参照物：散装与大包装、单个与整箱的量感要能判断。

### 卖点结构

- 产地：具体产地名要说得出（写到市/县级别更有说服力）
- 时令：什么季节、什么时候最甜/最新鲜
- 规格：重量、颗粒大小、净重、包装方式
- 运输：冷链、发货时效、坏果赔付承诺需真实存在
- 处理方式：是否可即食、清洗方式、烹饪建议

### 红线（最严格的部分）

普通食品与生鲜不得表述为具有疾病预防、治疗、身体功能改善或特定健康功效。禁止出现：

- 疾病预防与治疗、替代药物的表述
- 「无副作用」「安全无虞」「零风险」
- 「增强免疫力」「降三高」「抗癌」「减肥」等功效词
- 未经核验的绿色食品、有机、地理标志、无公害等认证标识
- 虚构的销量、复购率、用户评价

优先只用可验证的事实：产地、时令、规格、口感风味、加工工艺、包装、真实场景。

保健食品与普通食品的法律属性不同；未确认目标市场允许范围前一律按普通食品保守执行。

## 交付前自检

- 品类判断是否正确（皮草 / 生鲜）？
- 材质与品类是否真实对应，没有把仿品说成真品？
- 食品是否出现任何功效暗示？
- 规格、产地、认证是否都有依据，没有编造？
- 场景与卖点是否匹配目标人群？
