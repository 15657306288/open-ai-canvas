# 电商合规与证据分级

本技能用于保守执行与风险筛查，不是法律结论。平台规则与监管要求会变化；涉及当前规则时以官方最新来源为准，无法核验就写「尚未核验」。

## 先判宣称类型，不要只做敏感词替换

| 宣称类型 | 例子 | 处理原则 |
| --- | --- | --- |
| 商品事实 | 材质、净含量、规格、产地、配料 | 以包装、参数表、合同、检测或用户确认资料为准 |
| 性能效果 | 更耐用、更快、更静音 | 需要可解释的参数、测试或机制；不把推测写成事实 |
| 数据 | 20kg、99%、3倍、未检出 | 必须可追溯；来源不明时不用精确数字 |
| 认证资质 | FDA、CE、有机、专利、非遗 | 只能基于真实有效且适用于本商品与市场的材料 |
| 比较 | 比普通款更强、优于竞品 | 需统一口径与可比条件；不虚构竞品数据、不贬损 |
| 价格稀缺 | 最低价、全网最低、限量 | 需与当前真实销售条件一致 |
| 用户评价销量 | 10万+好评、复购第一 | 只引用真实可核验数据，不模拟消费者证言 |
| 健康医疗功效 | 治疗、修复、降血糖、增强免疫 | 高风险；先确认产品法律属性与允许宣称范围 |

## 四级证据状态

- **已确认**：用户材料或可靠来源直接支持，可直接用。
- **有依据**：可由已确认事实合理翻译，但不能扩大含义。
- **待补证**：需要检测、认证、官方规则或批准范围，必须改成中性表达或占位符。
- **禁止**：明显编造、误导、越权功效、虚假背书，绝不进入成稿。

最终稿只能使用「已确认」和「有依据」。

## 高风险表达

绝对化与保证性表达（最好、第一、唯一、100%、绝对、彻底、永久、零风险、保证有效）风险较高，但是否违法取决于语境、证据、司法辖区与平台规则。

- 能用客观参数就不用空泛最高级。
- 能写「基于某测试/某条件」就不要写无条件保证。
- 无证据时删除或降级，不是把「最」换成「更」就认为安全。

医疗健康类不要靠加「非医疗产品」「效果因人而异」免责声明来补救本身不允许的宣称。食品、保健品、医疗器械、健康护理、儿童与孕产妇用品按保守口径处理。

## 对比与竞品

- 使用一致口径与同一比较条件。
- 不虚构对手参数，不把主观评价写成事实。
- 更稳妥的是比较「本品规格/结构/使用条件」与「常见选择维度」。

## 数据与资质追溯

精确百分比、倍数、测试结果、「未检出」「零添加」、认证证书、产地年份、销量排名都必须能追溯。「企业有证」不等于「本 SKU 可用该宣称」。

## 上线前检查

- 每个关键事实是否有来源？
- 每个精确数字是否可追溯？
- 是否把「待补证」写成了确定事实？
- 是否存在医疗、健康、功效或保证性暗示？
- 是否存在虚构认证、销量、评价、排名或竞品数据？
- 跨境场景是否按目标市场重新判断，而非直接套用中国规则？
