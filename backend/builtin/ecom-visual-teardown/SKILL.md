# 店铺视觉拆解

输入是店铺截图、主图、详情页或竞品图。目标不是评价好看与否，而是**提取可执行的视觉规则**，让后续生成能复刻这套语言。

## 拆解维度

逐项给出可执行的结论，不要写「高级感」「大气」这类无法落地的形容词。

### 配色

- 主色、辅助色、强调色，给出十六进制值
- 配色比例：主色占比、点缀色占比
- 色彩性格：冷调/暖调、低饱和/高饱和、明快/沉静
- 背景倾向：纯白、纯色、渐变、实景、质感肌理

### 版式

- 主体占比：商品在画面中的面积比例
- 视角：正面、45 度、俯拍、平视、微距
- 留白：留白位置与比例
- 视线流向：视觉重心如何引导（中心构图、对角线、三分法）
- 图文关系：文案在上/下/侧，图文比例

### 摄影

- 布光：自然光、棚拍、柔光箱、硬光、逆光、轮廓光
- 光比与阴影：硬阴影还是柔和过渡
- 景深：背景虚化程度
- 机位高度：平视、微俯、微仰
- 道具与场景：生活场景、纯色背景、几何道具

### 材质与细节

- 材质表现手法：微距特写、纹理强化、反光控制
- 工艺细节是否可见：缝线、接口、材质纹理
- 后期倾向：磨皮程度、饱和度、对比度

### 排版与文字

- 字体印象：细衬线、无衬线、粗黑、手写感
- 字号层级：标题与正文的比例关系
- 文字位置：贴边、居中、留白处
- 文字密度：信息量大小

## 输出格式

用以下结构产出设计简报：

```markdown

- 主色：#XXXXXX（占比约 X%）
- 辅助色：#XXXXXX
- 强调色：#XXXXXX
- 背景：<描述>

**版式**
- 主体占比：X%
- 视角：<描述>
- 构图：<描述>
- 留白：<描述>

**摄影**
- 布光：<描述>
- 景深：<描述>
- 机位：<描述>
- 场景/道具：<描述>

**材质与细节**
- <描述>

**排版与文字**
- 字体印象：<描述>
- 字号层级：<描述>
- 文字密度：<描述>

## 可复用规则

- 规则 1：<可直接执行的约束>
- 规则 2：<可直接执行的约束>
- 规则 3：<可直接执行的约束>

- <生成时必须保持一致的元素>
```

## 约束

- 只描述图上真实存在的元素，不脑补品牌故事、销量、材质成分。
- 看不到的维度写「样本未覆盖」，不要用常识补齐。
- 「禁止漂移项」必须是图上明确存在、且换掉就变了风格的元素（配色、材质表现方式、构图习惯）。
- 样本少于 3 张时，说明结论稳定性有限。
- 拆解结果是风格参考，不是让用户盗用他人商标、文案或产品图；不得建议复刻他人品牌标识。
